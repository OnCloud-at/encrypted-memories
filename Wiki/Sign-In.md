# Sign In

Encrypted Memories requires an existing Proton account.

1. Select **Sign in with Proton**.
2. Complete Proton’s sign-in flow in the browser.
3. Approve the return to Encrypted Memories.
4. Wait while the app validates the session and opens the encrypted photo library.

The app does not collect the Proton password. Session credentials are stored in the platform Keychain with device-only accessibility.

## Platform presentation

- **iPhone and iPad:** Sign-in appears before the main tab interface.
- **Mac:** Sign-in appears in the main library window.

Both routes use the same authentication lifecycle and Proton Drive session core.

If the browser completes sign-in but the app does not continue, see [[Troubleshooting|Troubleshooting]].
