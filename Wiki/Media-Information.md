# Media Information

The information screen shows the metadata Encrypted Memories knows about the current photo or video.

Available fields can include:

- Capture date and time
- File name and media type
- Pixel dimensions and file size
- Camera or device information when available
- Location and resolved place name
- Album memberships
- Video or Live Photo details

Missing fields stay absent instead of being guessed. Location is shown only when the app has positive location metadata for the item.

- **iPhone and iPad:** Open the information sheet from the Viewer.
- **Mac:** Open the Viewer information panel.

The platforms present the panel differently but use the same metadata and album-membership sources.
