# Uploads and Upload Queue

Manual uploads and the Upload Queue are currently Mac-only app screens.

## Manual upload

Use the Library toolbar or the File menu to select photos, videos, or a folder. Manual uploads use the same duplicate protection and durable queue as backup work.

## Upload Queue

Open **Show Uploads** to review active, completed, and failed work. Recoverable failures can be retried. Closing the queue does not cancel durable work.

## Folder backup

The Mac Settings screen can register folders for continuing backup. macOS can request renewed access to a folder. Removing a registered folder stops future synchronization for that folder.

iPhone and iPad do not expose manual file or folder upload screens. Their Apple Photos upload path is [[Backup and Photo Library Sync|Backup-and-Album-Sync]].
