# Security Policy

## Supported versions

Security fixes are applied to the current App Store release and the default branch. Older releases may require an update before they receive a fix.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/OnCloud-at/encrypted-memories/security/advisories/new) for security-sensitive reports.

Include the affected version, platform, reproduction steps, impact, and any relevant logs with secrets and personal data removed. Do not open a public issue for an unpatched vulnerability.

Maintainers will acknowledge a complete report, assess its severity, and coordinate a fix and disclosure timeline. Please do not publish details before that coordination is complete.

## Scope

Reports about Encrypted Memories source code and release artifacts are in scope. Proton accounts, Proton services, and the Proton Drive SDK follow Proton's own security reporting process.
