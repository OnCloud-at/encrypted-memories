# Repository constraints

- Bound suggestion qualification by the query result limit. Keep the six-match floor. A coverage-scaled threshold above 400 rejected every concept in libraries above 100,000 indexed assets. See `MLSearchConceptDiscovery.swift`.
- Check refresh ownership before publishing any asynchronous result. Cancellation alone does not reject an older overlapping call. Propagate cancellation to detached workers. See `SmartSearchDiscoveryModel.swift`.
- Distinguish failed visual queries from successful empty results. A failed sensitive gate must suppress previews and remain retryable. Never finalize visual completion from failure. See `SmartSearchDiscoveryModel.swift` and `MLSearchConceptDiscovery.swift`.
- Preserve interactive search while automatic work yields. Resource leases can report active user interaction even for an admitted interactive request. Apply suggestion preemption without cancelling the user's own query. See `MLSmartSearchLifecycle.swift` and `LibraryResourceCoordinator.swift`.
- Use `scripts/build-paths.sh` and its build lock for every SwiftPM/Xcode gate. Do not create per-worktree caches or remove another build's lock. Vendor SDK sources must match the pinned commit, client rename, and both versioned patches before testing.
- Do not infer the library size from the indexed count. A lower count can mean unfinished indexing. Only an authoritative inventory permits reconciliation. Preserve the guarded coverage update in `MLSmartSearchLifecycle.swift`.
- Close each streaming owner explicitly; do not rely on loader deinit to cancel tasks that retain the loader. Individual AVFoundation request cancellation must preserve shared prefetch. Never close another player's account admission gate. See `VideoStreaming.swift`, `ProtonVideoResourceLoader.swift`, and `VideoPrefetchCompletion.swift`.
- Promote a demanded prefetch through its original governor priority handle. Swift task priority does not change the governor queue. Preserve the demand-scoped upload suspension and one fetch per block. See `ProtonRequestGovernor.swift` and `PhotoVideoStreamSource.swift`.
- Renew a persistent view's activity after a runtime generation reset. An old registration must neither block new activity nor end another owner's activity. See `LibraryRuntimeState.swift` and the search hosts.
- Accept zero-only XAttr sizes beyond actual revision blocks. Proton's legacy web writer appends a zero remainder for exact chunk multiples and empty files. Strict count equality rejects valid uploads. Reject missing or nonzero unmatched sizes; preserve oversized decrypted-block prefix compatibility. See `PhotoVideoStreamSource.swift` and its regression tests.
- Claim one per-block encrypted fetch atomically before cache lookup. Demand can arrive before prefetch registration; observing only the prefetch dictionary produced 20 HTTP fetches for 20 concurrent requests. Preserve a continuous demand priority scope across failed-prefetch retry. See `ProtonVideoResourceLoader.swift`.
- Fence cache publication inside the disk write with the player owner. An account cache generation alone does not reject a queued write after player close. Finish pending AV loading requests once on owner close; AV cancellation owns its own terminal result. See `VideoByteRangeCache.swift`, `VideoCacheWriteOwner.swift`, and `VideoLoadingRequestCompletion.swift`.
- Give every iOS export and support report its own UUID directory. Per-operation cleanup must never delete the shared ShareExports root or another operation's files. Preserve cold-launch cleanup. See `MobileSelectionSupport.swift` and `MobileShareExportTests.swift`.
- Preserve native video transport control unless real-device tests establish an equivalent intent contract. Custom resume logic can override native pause, replay, Picture in Picture, or audio interruptions. Keep automatic waiting and current buffer sizes; readiness must not issue play commands. See `VideoPlaybackController.swift` and `MobilePhotoViewer.swift`.
- Accept both CoreDevice UUIDs and physical device identifiers when selecting a local installation target. Connected WLAN devices can report `connected`, not an `available` prefix. Match the exact device name and physical reality. See `scripts/rebuild.sh`.
- Keep share-file ownership alive across payload copies and partial-share promotion. A dismissed export controller must not be retained across the download; its cancelled task still owns cleanup until the backend returns. Keep active share files until native dismissal completes. See `MobileSelectionSupport.swift`.
- Update existing accessibility elements when selection changes. Rebuilding only on viewport movement leaves VoiceOver's selected state stale after a press; replacing focused elements is unnecessary. See `MetalGridAccessibilityProvider.swift`.
- Keep the required `PROJECT-TRAPS.md` exception explicit in both `.gitignore` and `scripts/check-public-tree.sh`. Allowing the file in Git alone still fails repository hygiene. Do not allow private audit reports or broader Markdown patterns.
- Only the active timeline tab may join the launch-banner matched-geometry group. iPad keeps Library and Search tabs mounted in one namespace; both previously advertised a source and SwiftUI reported undefined geometry. Preserve the loading-cover handoff and inactive-tab state. See `LibraryActivityBanner.swift` and `MobileTimelineScreen.swift`.
- Clean up fixture-created scenes even when a hosted test throws. Reactivate the original scene and choose a foreground-active scene for window anchors. Programmatic iPadOS 27 tab selection can leave native search inactive; activate the real scene-owned search controller and still require its attached field. Do not change production search layout to satisfy synthetic tab selection. See `MobileSignedInMultiwindowTests.swift` and `MobileSceneOwnershipTests.swift`.
